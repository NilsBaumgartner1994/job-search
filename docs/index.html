⏳ Lokale Änderungen übernehmen

Deine Status-Änderungen sind bisher nur in diesem Browser gespeichert (localStorage). So landen sie im Repo:

  1. Änderungen kopieren antippen (oder das JSON unten manuell kopieren)
  2. KI-Agent-Workflow öffnen ↗
  3. Dort „Run workflow“ → Branch wählen → das JSON in das Feld aenderungen einfügen → starten
  4. Nach dem Lauf lädt diese Seite die neuen Daten — übernommene Änderungen werden hier automatisch aufgeräumt

Der Workflow übernimmt die Änderungen als menschliche Entscheidungen (👤) und triagiert danach weitere neue Jobs mit der KI.
